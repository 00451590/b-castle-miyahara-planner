# B・キャッスル宮原 3階 1LDK · 共同配置プランナー

GitHub Pages 上で動く家具配置（2D / 3D）＋買い物リスト＋予定の1ページアプリです。  
同じ部屋コードを共有すれば、ブラウザ同士でリアルタイム共同編集できます。

## 公開URL

デプロイ後:

`https://00451590.github.io/b-castle-miyahara-planner/`

共同編集の例:

`https://00451590.github.io/b-castle-miyahara-planner/?room=fuji-koga`

## 使い方

1. 上の Pages URL を開く
2. 右上に部屋コード（例: `fuji-koga`）を入れて「共同編集を開始」
3. 相手に `?room=...` 付きの同じ URL を送る

配置・買い物リスト・予定・メモは同期されます。片方だけでもブラウザに自動保存されます。JSON の書き出し／読み込みも可。

## 画面

- **配置** … 間取り上に家具をドラッグ。パレット／カスタム寸法・回転（`R`）・削除
- **3D** … 同じ配置を立体表示
- **リスト・予定** … 買い物リスト（予算合計）・ToDo・共有メモ

## 注意

- 寸法は掲載情報からの **推定** です。契約・発注前に必ず実測してください。
- 共同編集は P2P のため、回線によっては繋がりにくいことがあります。その場合は JSON の受け渡しでも可。
- 間取り画像の著作権は各掲載元にあります。個人の検討用途を想定しています。
